# 🎨 Frontend Module

This directory contains all client-facing UI templates, styles, and scripts for the Clinical Management System.

## Files:
- **`login.html`**: Multi-portal authentication gateway (Admin, Patient, Doctor) with 1-click auto-fill buttons.
- **`register.html`**: Patient self-registration form (Indian contacts, emergency contact, allergy info).
- **`admin.html`**: Hospital administrator console (doctor onboarding, appointment schedules, revenue in ₹, diagnostic test report generation).
- **`patient.html`**: Patient health console (appointment booking, consultation histories, fee payments in ₹, diagnostic test reports, prescription records).
- **`doctor.html`**: Physician workbench (appointment queue, fee tracking in ₹, digital prescription writer, lab reports review).
- **`style.css`**: Complete responsive CSS3 medical styling, badges (`.badge-paid`, `.badge-unpaid`), and print stylesheet (`@media print`).
- **`script.js`**: Tab navigation switching, modal triggers, doctor specialty filtering, and print handlers.
